## 📜 چکیده علمی

این پلتفرم یک سامانهٔ محاوره‌ای مبتنی بر هوش مصنوعی است که با بهره‌گیری از روش‌های **پردازش زبان طبیعی (NLP)**، **تحلیل احساس (Sentiment Analysis)**، **استخراج ویژگی‌های شخصیتی مبتنی بر مدل پنج‌بزرگ شخصیت (Big Five)** و یک **موتور چت هوشمند**، رفتار کاربران را در شبکه‌های اجتماعی تحلیل می‌کند.  
معماری پیشنهادی کاملاً **مستقل از سرویس‌های خارجی** بوده و می‌تواند به‌صورت **تماماً محلی (بدون اینترنت)** یا **مستقر روی سکوهای ابری (Vercel)** فعالیت کند.  
هدف اصلی: **کاوش خودکار الگوهای شناختی و عاطفی از محتوای متنی** و ارائهٔ تحلیل از طریق یک رابط چت طبیعی و زیبا.

---

## 🔥 ویژگی‌های کلیدی

- **تحلیل احساس دو زبانه (فارسی و انگلیسی)** – نمره‌دهی عاطفی با استفاده از واژگان گستردهٔ مثبت/منفی در هر دو زبان.
- **شخصیت‌شناسی خودکار** – تشخیص ۵ بُعد اصلی شخصیت (بازبودن به تجربه، وظیفه‌شناسی، برون‌گرایی، سازگاری، روان‌رنجوری) بر اساس تحلیل واژگان کلیدی.
- **طبقه‌بندی نیت کاربر (Intent Classification)** – تشخیص خودکار سلام، خداحافظی، تشکر، درخواست تحلیل و غیره با استفاده از قوانین قدرتمند.
- **چت هوشمند و متنوع** – پاسخ‌های تصادفی و طبیعی به پیام‌های متداول؛ تحلیل خودکار برای جملات عمومی.
- **معماری سبک و بدون وابستگی خارجی** – فقط با Express.js و بدون کتابخانه‌های سنگین NLP.
- **رابط کاربری مدرن و واکنش‌گرا** – طراحی زیبا با انیمیشن تایپینگ، سایه‌ها، و پشتیبانی از موبایل.
- **سازگار با Vercel** – استقرار بدون پیکربندی پیچیده روی محیط serverless.
- **پایگاه داده ساده (JSON)** – ذخیرهٔ تاریخچهٔ گفتگوها در فایل JSON (بدون نیاز به SQL).
- **کاملاً آفلاین** – همهٔ قابلیت‌ها بدون نیاز به اینترنت یا API خارجی کار می‌کنند.

## 🧱 معماری فنی

```

client (browser)
│
▼
Express.js Server (main.cjs)
├── routes/chat.js            ← API endpoints
├── services/ai-chat.js       ← موتور چت محلی (تحلیل احساس و شخصیت)
└── public/
└── index.html           ← رابط کاربری نهایی

```

**جریان داده:**
1. کاربر پیام را از طریق `POST /api/chat/message` ارسال می‌کند.
2. `routes/chat` پیام را دریافت کرده و به `services/ai-chat.js` می‌فرستد.
3. موتور چت ابتدا intent پیام را تشخیص می‌دهد:
   - اگر **تحلیل** باشد → تحلیل احساس و شخصیت انجام و پاسخ مناسب تولید می‌شود.
   - اگر **جملهٔ عمومی** باشد → وضعیت روحی و ویژگی شخصیتی غالب از روی واژگان استخراج شده و به کاربر بازتاب داده می‌شود.
   - اگر **سلام/خداحافظی/تشکر** باشد → یکی از پاسخ‌های از پیش تعریف‌شده به‌صورت تصادفی انتخاب می‌شود.
4. پاسخ (به‌همراه جزئیات تحلیل در صورت وجود) در قالب JSON به کاربر بازگردانده می‌شود.

## 🛠️ تکنولوژی‌ها

| لایه | فناوری |
|------|--------|
| Backend | Node.js, Express |
| تحلیل احساس و شخصیت | الگوریتم‌های دستی مبتنی بر واژگان (بدون کتابخانهٔ خارجی) |
| پردازش زبان طبیعی (NLP) | توکنایزر ساده (regex)، نرمال‌سازی فارسی و انگلیسی |
| Frontend | HTML5, CSS3, JavaScript (Vanilla) |
| استقرار | Vercel (serverless) |
| ذخیره‌سازی (اختیاری) | JSON در `/tmp` (Vercel) یا `data/` (محلی) |

## ⚙️ نصب و راه‌اندازی محلی

۱. مخزن را کلون کنید:

```bash
git clone https://github.com/tetrashop/social-media-intelligence-platform.git
cd social-media-intelligence-platform
```

۲. وابستگی‌ها را نصب کنید:

```bash
npm install
```

۳. سرور را اجرا کنید:

```bash
npm start
```

۴. در مرورگر به آدرس http://localhost:3000 بروید.
   (صفحهٔ اصلی خودِ چت است، نیازی به /chat نیست.)

🌐 استقرار روی Vercel

پروژه از پیش برای Vercel تنظیم شده است. مراحل استقرار:

۱. اطمینان از push بودن آخرین تغییرات:

📡 API Endpoints

متد مسیر توضیحات
POST /api/chat/message ارسال پیام و دریافت پاسخ + تحلیل (در صورت نیاز)
GET / رابط کاربری چت

نمونه درخواست (curl)

```bash
curl -X POST https://social-media-intelligence-platform.vercel.app/api/chat/message \
  -H "Content-Type: application/json" \
  -d '{"message":"تحلیل کن امروز خیلی خوشحالم و پر از ایده‌های خلاقانه هستم","sessionId":"demo"}'
```

نمونه پاسخ

```json
{
  "response": "🧠 تحلیل هوشمند:\n- احساس: 1.00\n- شخصیت غالب: openness\n- کلمات کلیدی: تحلیل, کن, امروز, خیلی, خوشحالم",
  "analysis": {
    "sentiment": "1.00",
    "dominant": "openness",
    "keywords": "تحلیل, کن, امروز, خیلی, خوشحالم"
  }
}
```

🧪 تست‌ها

با ارسال پیام‌های زیر می‌توانید سلامت سامانه را بیازمایید:

· «سلام» → دریافت یکی از پاسخ‌های خوش‌آمدگویی تصادفی

· «goodbye» → پاسخ خداحافظی
· «چطوری؟» → پاسخ مناسب (جملهٔ عمومی با بازتاب حالت روحی)
